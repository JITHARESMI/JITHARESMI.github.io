# Jitha Resmi Rema — Gold Portfolio

The final version uses the original gold portfolio layout, with refined typography, spacing and straightforward copy. The portrait frame, role animation, scroll reveals, expandable experience and project dialogs remain in place.

## Open locally
Extract the ZIP and open `index.html`. Keep the `assets` folder alongside it. No Docker, Composer, npm or server is required. Manrope and Inter load from Google Fonts when online; Arial is the offline fallback.

## Edit
- `index.html`: page content and layout.
- `assets/site.css`: charcoal and gold colours, type, spacing and responsive styles.
- `assets/site.js`: navigation, animation and project dialogs.
- `assets/data.js`: project details and their implementation status.
- `assets/jitha-portrait.png`: supplied portrait.
- `cv.html`: complete résumé, with a print/save-to-PDF button.

## GitHub Pages
Back up your existing portfolio, then copy these files into the root of `JITHARESMI.github.io`. Keep `index.html` at the root and include `.nojekyll`. Commit and push to your publishing branch. This download has not changed the live website.

## Content
Experience follows the supplied CV. Project previews are labelled interface concepts with sample data. Project dialogs state what is implemented and what remains unfinished. Actual AI-related project features are retained; there are no claims about detecting AI-written content, awards or guaranteed recruitment outcomes. Some project links lead to the GitHub profile because a repository URL has not been confirmed.

## Checks
JavaScript syntax, local assets, HTML structure, anchors and ZIP integrity checked. Browser visual and device testing has not been performed. Review font loading, mobile navigation, project dialogs, experience disclosures and CV printing before publishing.

No analytics, contact-form backend or API keys. Contact links open email, telephone or social profiles. Reduced-motion preferences and a manual motion control are supported.
